Frequently Asked Questions

How does TinderKat work?

The app connects to a global database via "The CAT API to fetch random images. Then, it pulls personality data from a local JSON file to give each cat a unique name, job, and location"

Can I actually adopt these cats?

While these specific matches are for fun, we encourage users to visit their local animal shelters if they are looking for a real-life furry companion!

Where does the data come from?

The images are provided by public feline repositories, and the technical implementation uses HTML5, Tailwind CSS and asynchronous Javascript

Are my favorites saved?

Yes! We use the browser's Local Storage, which means your matches will be saved even if you close the tab or refresh the page
